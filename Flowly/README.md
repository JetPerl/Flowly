This is an [**Expo**](https://expo.dev) project (React Native).

# Getting Started

> **Note**: This app uses native modules (maps, reanimated, skia, etc), so **Expo Go is not enough**. Use a development build (`expo-dev-client`) via `npm run ios` / `npm run android`.

## Step 1: Install dependencies

```sh
npm install
```

## Step 2: Start the bundler

```sh
npm start
```

## Step 3: Build and run your app

### Android

```sh
npm run android
```

### iOS

```sh
npm run ios
```

If everything is set up correctly, you should see your new app running in the Android Emulator, iOS Simulator, or your connected device.

## Env vars

- Use `EXPO_PUBLIC_GOOGLE_MAPS_API_KEY` to provide the Google Maps key at runtime (used for Places/Geocoding requests).
